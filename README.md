# RoboCar - Obstacle Avoidance 

A Python simulation of an autonomous rover that navigates using ultrasonic sensor logic.

Built on: Pydroid 3 (Android phone) - no laptop

How it works:
- Simulates HC-SR04 ultrasonic sensor
- If distance < 20cm: stops and chooses safe direction
- Else: moves forward
- This is core logic for self-driving cars

Tech: Python, OOP, Randomization, Autonomous Navigation

Next step: Deploy to real Arduino Uno + motor driver.
